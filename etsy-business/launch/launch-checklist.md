# Launch checklist

## Before opening the shop
- [ ] Name cleared: Etsy search, .co.uk registrar, IPO trademark search, Companies House
- [ ] Domain bought and parked
- [ ] Shop account created (personal/sole-trader details correct: this income is itself self-assessment income: eat the dog food)
- [ ] Payment + billing verified; setup fee paid; VAT status recorded (no VAT number yet: fees carry 20% VAT: priced in)
- [ ] Fee stack re-verified in Seller Dashboard against research/etsy-policy.md

## Shop shell
- [ ] Banner + icon per visual identity (positioning.md)
- [ ] Shop title with keywords ("UK spreadsheets for small business...")
- [ ] About section (positioning.md draft, human-verified claims)
- [ ] Shop policies: digital-download terms, support promise, refund stance
- [ ] Shop sections created: Tax & Bookkeeping / By Trade / Client & Sales Tools / Bundles
- [ ] Share & Save activated
- [ ] Etsy app installed, notifications on

## Per listing (from seo.md SOP)
- [ ] QA checklist green (qa-sop.md) and logged
- [ ] Title/tags/category/attributes from listing-master.csv
- [ ] AI disclosure set where applicable
- [ ] 8 images + video from image-briefs.md
- [ ] Both formats + guide attached; ≤5 files, ≤20MB each
- [ ] Description: opening keywords, WHAT'S INSIDE, HOW IT WORKS, FORMATS, FAQ, SUPPORT, disclaimer (finance)
- [ ] Price per architecture ladder
- [ ] Cross-sell image 8 + footer links

## First 48 hours
- [ ] Test purchase from a second account; download both formats on a clean machine
- [ ] First 10 Pinterest pins live (Share & Save links)
- [ ] Follow-up message template active
- [ ] Stats baseline recorded

## Standing compliance
- [ ] No tax/legal advice claims anywhere; no "MTD compliant filing"
- [ ] No trademarked names in tags/titles
- [ ] No incentivized reviews, no fake urgency
- [ ] Licence register current for every third-party asset
