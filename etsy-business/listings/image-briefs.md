# Image briefs: the listing image system

Dated 2026-08-31. One reusable 8-slot template (Figma/Canva free) so every listing costs ~30 minutes of imagery and the shop reads as a product family in search. Brand rules from strategy/positioning.md: deep green + off-white + amber accent, one sans typeface, no pastel-planner aesthetic, no stock-photo hands.

## The 8-slot system (every listing)

| Slot | Content | Rules |
|---|---|---|
| 1 HERO | Laptop (+phone where relevant) mockup of the MOST alive view (dashboard/Today view), 3-5 word benefit headline, UK badge where relevant, edition chip (2026/27) | Headline ≤5 words; readable at 120px thumbnail; identical layout across catalogue |
| 2 WHAT'S INSIDE | Grid of tab thumbnails with labels | Max 8 items; real screenshots, not icons |
| 3 CLOSE-UP | The money shot: SA summary / quote calculator / client card, with realistic demo data | Demo data must look real (see production-sop.md demo-data rules) |
| 4 HOW IT WORKS | 3 numbered steps | Verbs first: "Enter... Watch... Download..." |
| 5 TRUST | Callouts: locked formulas · both formats included · video guide · free tax-year updates | The four review-complaint killers, always these four |
| 6 SUPPORT | 24h reply promise card + refund stance | Plain language |
| 7 FAQ | Top 3 FAQ as a card | Pulled from listing copy |
| 8 FAMILY | Cross-sell grid: "Complete your office" with bundle price | Same grid across the family, current listing highlighted |

## Video (every listing, 15-30s)

Screen capture: rows being typed → dashboard/Today view updating → end card with logo + "Google Sheets & Excel included". No voiceover needed; captions burned in. Tool: OBS/CapCut.

## Mockup production

- Base mockups in Photopea (free) from own screenshots; laptop/phone frames from free mockup sources with commercial licences only (log each in the licence register, qa-sop.md).
- Screenshot discipline: 2x scale, light theme, demo data loaded, no personal info, consistent zoom.

## Thumbnail A/B rule

Month 2+: for the top 3 traffic listings, test hero headline variants (benefit vs audience-call: "Your year, added up." vs "For UK sole traders."). One change at a time, 2 weeks per test, decide on CTR from Etsy stats.
